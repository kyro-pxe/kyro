# Security Policy

## Supported versions

Kyro is in early development and has no releases yet. Only the latest version
is supported: currently the tip of the `main` branch, and once releases exist,
the latest release. Fixes are not backported to older versions.

| Version        | Supported |
| -------------- | --------- |
| Latest         | Yes       |
| Anything older | No        |

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions or
pull requests.

Report them privately through GitHub's private vulnerability reporting:

1. Go to the [Security tab](https://github.com/kyro-pxe/kyro/security) of the
   repository.
2. Click **Report a vulnerability**, or open
   <https://github.com/kyro-pxe/kyro/security/advisories/new> directly.
3. Describe the issue, including the affected version or commit, steps to
   reproduce, and the impact you expect.

Reports are handled on a best-effort basis by the maintainers. Please give us
a reasonable amount of time to investigate and fix the issue before disclosing
it publicly. We will credit you in the advisory unless you prefer otherwise.
